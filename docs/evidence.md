# Claims and their evidence

Every claim the README and guides make, and what backs it. A `test` entry names a test
that fails if the claim stops being true (`tests/evidence.rs` checks each name exists); a
`corpus` entry names a scenario in `tests/compat/` whose pinned reader output proves it
on a real record; `D<n>` is a measured decision in `design/decisions.md`. Claims with
only a measurement are marked as such.

| claim | evidence |
|---|---|
| Every run writes a record: `scan_started` first, `scan_config` second, exactly one terminal event last, nothing after | `test:every_documented_event_type_is_reachable`, `test:adhoc_scan_writes_a_verifiable_record`, `corpus:direct-mixed` |
| Ctrl-C leaves a finalised record; `completed` + `abandoned` + `not_started` = `planned`; exit 130 | `test:an_interrupt_mid_scan_drains_and_reconciles`, `test:abandoned_is_distinct_from_never_started`, `test:a_forced_interrupt_is_recorded_as_not_graceful`, `corpus:interrupted` |
| `output remainder \| run --pairs -` probes exactly what was outstanding and links the records | `test:output_remainder_round_trips_into_a_rescan`, `test:remainder_is_exact_when_a_target_is_only_partly_probed`, `test:recognises_the_resumed_from_directive`, `corpus:resumed` |
| A writer failure or a worker panic forces `scan_failed`, never a clean completion | `test:a_writer_failure_on_a_probe_result_is_not_swallowed`, `test:a_writer_failure_on_a_warning_is_not_swallowed`, `test:a_panicking_worker_is_not_reported_as_a_clean_completion` |
| A killed scan keeps every probe its spans stood for, up to the last gzip frame | `test:a_sigkilled_scan_keeps_the_probes_its_spans_stood_for`, `test:a_truncated_compressed_partial_reads_up_to_its_last_frame` |
| Probe order is a bijection, reproducible from the recorded seed | `test:bijection_over_representative_sizes`, `test:bijection_across_seeds`, `test:a_seed_makes_probe_order_reproducible` |
| Spans give the same answers as one row per probe | `test:a_span_covers_exactly_the_endpoints_its_rows_would_have`, `test:a_span_record_reconciles_its_counts`, `test:get_finds_results_that_only_exist_inside_a_span`, `corpus:direct-mixed`, `corpus:direct-rows` |
| A faithful SOCKS5 proxy yields `closed` distinctly; a collapsing one yields `error`, never a fabricated `closed` | `test:faithful_proxy_reports_closed_for_a_refused_port`, `test:collapsing_proxy_yields_error_not_a_fabricated_closed`, `test:judgement_table_is_conservative`, `corpus:socks5-full`, `corpus:socks5-open-only`; measured D23 |
| `transport test` measures fidelity rather than assuming it; `ssh -D` is `open_only` | `test:faithful_proxy_measures_as_full`, `test:collapsing_proxy_measures_as_open_only`, `test:unreachable_proxy_yields_unknown_not_a_guess`; measured D8, D23 |
| The proxy's connection cap, not `concurrency`, decides; a burst does not predict it | measured D24, D25 (no automated test — it needs a real capped proxy) |
| HTTP CONNECT proxies are `open_only` by construction; non-open results carry the status line; `fidelity = "full"` is refused | `test:an_http_exit_is_open_only_by_construction`, `test:a_refused_destination_is_error_carrying_the_status_line`, `test:an_http_transport_declaring_full_fidelity_is_refused`, `corpus:http-proxy`; measured D34 |
| A chain's fidelity is its exit hop's; hops mix protocols in either order; failures name the hop | `test:a_chain_takes_its_exit_hops_fidelity`, `test:chains_mix_http_and_socks5_hops_in_either_order`, `test:a_failing_http_hop_is_blamed_by_index_not_reported_as_a_port_verdict`, `test:a_mixed_chain_records_each_hop_with_its_protocol`, `corpus:chain-http-socks5`; measured D33 |
| A pool assigns endpoints deterministically and records `via`; its fidelity is its weakest member's | `test:the_pool_reports_its_weakest_member`, `corpus:pool` |
| Every proxied kind resolves hostnames through the transport (no local DNS leak) | `test:every_proxied_kind_supports_remote_dns_and_direct_does_not`, `test:hostnames_are_handed_to_the_proxy_unresolved`, `test:hostname_targets_are_sent_unresolved` |
| Banners are read without sending a byte, on by default; hostile bytes never reach the terminal but stay in the record | `test:banners_are_read_by_default_and_can_be_turned_off`, `test:a_hostile_banner_is_neutralised_on_screen_but_kept_in_the_record`, `test:a_banner_travels_back_through_the_tunnel`, `corpus:banner-tls` |
| The TLS probe is off by default and the record says what was sent | `test:off_by_default_sends_nothing`, `test:the_tls_probe_is_off_by_default_and_the_record_says_so`, `test:a_service_that_greets_is_never_probed` |
| The TLS probe yields certificate, cipher and ALPN from a 1.2 server and `protocol_version` from a 1.3-only server, verified against OpenSSL | `test:the_tls_probe_agrees_with_openssl_s_server`, `test:a_tls13_only_server_is_recorded_as_a_protocol_version_alert`, `test:the_tls_probe_records_the_leaf_and_verify_accepts_it`, `corpus:banner-tls` |
| The bytes the TLS probe sends are exactly those documented | `test:the_documented_client_hello_matches_the_bytes_sent`, `test:the_client_hello_is_a_well_formed_tls12_record` |
| Peer-controlled parsers (SOCKS5, HTTP, TLS, config, record, specs) never panic | `test:disconnect_mid_handshake_never_panics`, `test:malformed_and_missing_responses_never_panic_and_never_report_open`, `test:hostile_and_broken_flights_never_panic_and_say_what_happened`; seven fuzz targets replayed in CI |
| A trickling peer cannot choose how long a probe takes | `test:a_trickling_proxy_cannot_outrun_the_budget`, `test:a_trickling_http_proxy_cannot_outrun_the_budget`, `test:a_trickling_server_cannot_outrun_the_ceiling` |
| Credentials never reach the record, the screen, or an error message; inline passwords are refused | `test:credentials_never_reach_the_record`, `test:caret_rendering_never_prints_a_credential`, `test:inline_password_is_rejected_with_alternatives`, `test:wrong_credentials_are_reported_clearly_without_leaking_the_password`, `test:basic_auth_succeeds_and_a_bad_password_is_reported_without_leaking_it` |
| Results agree with nmap: direct, filtered, through SOCKS5, and through HTTP CONNECT | `test:agrees_with_nmap_on_open_and_closed`, `test:agrees_with_nmap_on_filtered`, `test:a_proxied_scan_agrees_with_nmap_direct`, `test:a_scan_through_an_http_proxy_agrees_with_nmap` (CI's differential job) |
| Probe sockets close with `SO_LINGER{on,0}` (the 7.5× throughput mechanism) | `test:linger_zero_is_actually_applied`; measured D9 |
| Resource pressure is reported once, with a remediation derived from this host | `test:resource_pressure_is_reported_once_with_remediation`, `test:every_pressure_has_a_code_and_remediation` |
| Exit codes are `0/1/2/3/130`, and a usage error is `1`, not `2` | `test:the_documented_exit_codes_match_the_code`, `test:usage_errors_exit_one_and_help_exits_zero` |
| `docs/cli.md`, the profile table, the schema's codes and closed sets, the `unsafe` inventory, the man pages and `config init` cannot drift from the code | `test:every_flag_on_every_command_is_documented`, `test:the_documented_profiles_match_the_builtins`, `test:spec_warning_codes_match_the_code`, `test:the_closed_enumerations_match_the_spec`, `test:security_doc_accounts_for_every_unsafe_block`, `test:committed_man_pages_are_current`, `test:template_documents_every_profile_field`, `test:template_documents_every_defaults_field` |
| Every schema version this build reads has a record in the corpus, and every reader still reads it exactly as pinned | `test:the_corpus_covers_every_schema_version_this_build_reads`, `test:every_corpus_record_reads_back_exactly_as_expected`, `corpus:v1-0.2.2` |
| A `scanr.toml` from any release validates and plans under this build | `test:every_prior_config_template_still_validates_and_plans` |
| Test coverage cannot regress unnoticed | CI enforces an 85% region-coverage floor (`cargo llvm-cov`, `testsupport` excluded); measured 91.1% on 2026-08-25 at `1.0.0-rc.1` + D37 (was 89.3% in July). The figure counts inline `#[cfg(test)]` modules, so it flatters shipped code by a few points |
| Performance: ~600,000 probes/s direct on loopback; ~10× nmap `-T5` on the same terms | measured D1, D26, D37 and `docs/tuning.md` (no automated test — a benchmark, not a property) |
